# Путь 2. Сразу главное

Этот маршрут нужен, чтобы быстро увидеть практическое ядро options: где риск, где `breakeven`, почему `payoff` важнее красивого прогноза, и как `theta`, `vega` и `implied volatility` могут испортить настроение.

Он не заменяет полный курс. Это карта главных рисков.

## Главная идея

В options мало сказать: "BTC вырастет" или "SPY упадет".

Нужно ответить:

| Вопрос | Почему важен |
| --- | --- |
| Где `breakeven`? | Цена может пойти в твою сторону, но недостаточно далеко |
| Какой `max loss`? | Без этого сделка не имеет рамки |
| Как выглядит `payoff`? | Он показывает сценарии на expiry |
| Что делает `theta`? | Время может съесть premium |
| Что делает `vega`? | Падение IV может ударить по option price |
| Где `liquidity`? | Wide spread может сделать хорошую идею плохой сделкой |

## Быстрый пример

| Параметр | Значение |
| --- | --- |
| Underlying | BTC |
| BTC price | $100,000 |
| Option | Long Call |
| Strike | $110,000 |
| Premium | $3,000 |
| Expiry | 30 дней |

`Breakeven = $110,000 + $3,000 = $113,000`.

| BTC на expiry | Intrinsic value | P/L |
| --- | ---: | ---: |
| $105,000 | $0 | -$3,000 |
| $110,000 | $0 | -$3,000 |
| $113,000 | $3,000 | $0 |
| $120,000 | $10,000 | +$7,000 |

## Практика

Ответь письменно:

1. Почему BTC = $110,000 не дает прибыли?
2. Почему BTC = $105,000 означает полный убыток premium?
3. Что может произойти с ценой опциона до expiry, если BTC стоит на месте?
4. Что будет, если BTC вырос, но `implied volatility` резко упала?
5. Какой вопрос нужно задать до входа: "куда пойдет рынок?" или "что должно случиться, чтобы payoff стал хорошим?"

## Мини-тест

1. Для long call `breakeven` считается как:
   - A. `strike - premium`
   - B. `strike + premium`
   - C. `premium / delta`

2. `Theta` чаще всего вредит:
   - A. покупателю option;
   - B. владельцу cash;
   - C. таблице Excel, если ее открыть до кофе.

3. `IV crush` - это:
   - A. рост цены underlying;
   - B. падение implied volatility после события;
   - C. принудительная ликвидация futures position.

Ответы: 1-B, 2-A, 3-B.
