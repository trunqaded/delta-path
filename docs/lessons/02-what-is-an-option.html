Урок 2

Что такое option

20-30 минут Уровень 2 Маршрут: оба Slug: what-is-an-option

Главная идея

Option - это контракт, который дает право, но не обязанность, купить или продать underlying asset по заранее заданной цене.

Option - это не просто ставка на рост или падение. Это право выбора, за которое покупатель платит premium.

Разбор понятий

option

Option - это контракт с правом выбора. Покупатель может использовать право, если это выгодно, или не использовать, если смысла нет. Поэтому покупатель платит premium: бесплатного права выбора рынок обычно не выдает.

underlying asset

Underlying asset - актив, от которого зависит option: BTC, ETH, SPY, AAPL. Option не живет сам по себе. Его цена реагирует на движение underlying, время до expiry, volatility и liquidity.

call

Call дает право купить underlying по strike. Для покупателя call базовая идея bullish: актив должен вырасти достаточно сильно, чтобы покрыть premium и выйти выше breakeven.

put

Put дает право продать underlying по strike. Его используют для bearish-идеи или защиты позиции. Например, long SPY put может работать как страховка от падения рынка.

strike

Strike - цена исполнения. Это не прогноз и не цель рынка, а фиксированная точка контракта. От strike считается intrinsic value, breakeven и форма payoff.

premium

Premium - цена option. Для покупателя long option это обычно максимальный убыток. Но premium также задает планку: рынок должен пройти не просто в правильную сторону, а достаточно далеко.

expiry

Expiry - дата истечения option. Время работает против покупателя, если цена и volatility не помогают. Поэтому "направление угадал" и "сделка заработала" - не одно и то же.

breakeven

Breakeven - цена, где итоговый P/L становится нулевым на expiry. Для long call это strike + premium, для long put - strike - premium.

intrinsic value

Intrinsic value - внутренняя стоимость option, если исполнить его сейчас или на expiry. У call это max(underlying - strike, 0), у put - max(strike - underlying, 0).

IV crush

IV crush - падение implied volatility после события. Option может подешеветь даже при правильном движении underlying, потому что рынок уже снял неопределенность с цены.

Простое объяснение

BTC стоит $100,000. Ты хочешь получить право купить BTC через месяц по $110,000. За это право ты платишь $3,000.

Если BTC улетит к $130,000, право купить по $110,000 выглядит очень полезным. Если BTC останется ниже $110,000, option может expire worthless.

Покупатель option платит за возможность, а не за гарантию прибыли. Рынок такие подарки не раздает.

Что может пойти не так

  • Актив вырос, но option не дал прибыль. BTC может вырасти до $105,000, но call strike $110,000 останется worthless на expiry.
  • Дешевый option кажется хорошим. Низкий premium часто означает низкую вероятность или дальний OTM strike.
  • Expiry кажется далекой. Время всегда часть цены. Позже это станет темой theta.

Исторический пример

Перед earnings, решениями ФРС или крупными crypto events options часто дорожают через implied volatility. После события может случиться IV crush: underlying идет в правильную сторону, но option дешевеет, потому что uncertainty исчезла.

Практика

ETH стоит $4,000. Ты покупаешь ETH call: strike $4,400, premium $150, expiry 21 день. Где breakeven, max loss, и что будет при ETH = $4,300 и $4,700? Для реального наблюдения цены используй ETH на CoinGecko.

Показать решение ETH call

Breakeven = $4,400 + $150 = $4,550. Max loss = $150. При ETH = $4,300 option expires worthless, P/L = -$150. При ETH = $4,700 intrinsic value = $300, P/L = +$150.

SPY стоит $500. Ты покупаешь SPY put: strike $480, premium $8, expiry 30 дней. Где breakeven для put, max loss, и что будет при SPY = $490 и $460? Для реального наблюдения используй SPY на Nasdaq.

Показать решение SPY put

Breakeven = $480 - $8 = $472. Max loss = $8. При SPY = $490 put expires worthless, P/L = -$8. При SPY = $460 intrinsic value = $20, P/L = +$12.

Мини-тест

1. Call дает право...

2. Put дает право...

3. Покупатель option платит...

4. Для long call breakeven обычно считается как...

5. Если option expires worthless, покупатель long option теряет...

Короткий вывод

  • Option дает право, но не обязанность.
  • Call - право купить.
  • Put - право продать.
  • Premium - цена этого права.
  • Движение underlying в правильную сторону не гарантирует прибыль.
