# Урок 1. Что такое опцион

Опцион - это контракт, который дает право, но не обязанность, купить или продать актив по заранее заданной цене.

Есть два базовых типа:

- Call: право купить актив.
- Put: право продать актив.

## Пример на BTC

BTC стоит $100,000.

Call со страйком $110,000 дает право купить BTC по $110,000.

Если BTC вырастет до $130,000, call может сильно вырасти в цене.

Если BTC останется ниже $110,000 к экспирации, этот call может сгореть.

## Главные переменные

- Цена базового актива.
- Strike.
- Premium.
- Время до экспирации.
- Implied volatility.
- Ликвидность.

## Мини-задача

BTC = $100,000.

Call strike = $110,000.

Premium = $3,000.

Ответь:

- Где breakeven?
- Какой максимальный убыток?
- Что будет при BTC = $105,000 на экспирации?
- Что будет при BTC = $120,000 на экспирации?
