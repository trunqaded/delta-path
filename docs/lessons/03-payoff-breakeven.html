Урок 3

Payoff и breakeven

20-30 минут Уровень 3 Маршрут: оба Slug: payoff-breakeven

Цель урока

Научиться смотреть на option не как на "ставку вверх/вниз", а как на набор сценариев. Payoff показывает, что будет с P/L при разных ценах underlying на expiry.

Главный вывод: правильное направление не гарантирует прибыль. Цена должна пройти через breakeven.

Long call как картинка

BTC стоит $100,000. Ты покупаешь long call: strike $110,000, premium $3,000. Значит, на expiry прибыль начинается только выше $113,000.

Формула без мистики

Long call intrinsic value: max(underlying price - strike, 0)

P/L: intrinsic value - premium

Breakeven: strike + premium

Таблица сценариев

BTC на expiryIntrinsic valueP/LВывод
$105,000$0-$3,000call сгорел
$110,000$0-$3,000на strike еще нет прибыли
$113,000$3,000$0breakeven
$120,000$10,000+$7,000прибыль после premium

Long put зеркально

Для long put прибыль появляется ниже breakeven. Если SPY = $500, put strike $480, premium $8, то breakeven = $472.

Что теперь проверять до входа

Где max loss?Для long option обычно premium.
Где breakeven?Цена, где P/L на expiry становится нулевым.
Где profit zone?Сценарии, где payoff реально покрывает premium.

Практика

ETH = $4,000. Long call strike $4,300, premium $120. Посчитай breakeven, max loss и P/L при ETH = $4,200, $4,420, $4,700.

Показать решение

Breakeven = $4,300 + $120 = $4,420. Max loss = $120. При $4,200 P/L = -$120. При $4,420 P/L = $0. При $4,700 intrinsic value = $400, P/L = +$280.

Мини-тест

1. Для long call breakeven считается как...

2. Max loss покупателя long option обычно равен...

3. Если underlying вырос, но не дошел до breakeven, long call...

Короткий вывод

  • Payoff показывает P/L по сценариям на expiry.
  • Breakeven важнее голого направления.
  • Long call имеет ограниченный max loss и растущий upside.
  • Long put имеет ограниченный max loss и зарабатывает на падении ниже breakeven.
