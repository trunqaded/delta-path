# Что такое option

Урок 2

20-30 минут · Уровень 2 · Маршрут: оба · `what-is-an-option`

## 1. Главная идея

`Option` - это контракт, который дает право, но не обязанность, купить или продать `underlying asset` по заранее заданной цене.

Самое важное в этом уроке: option - это не просто "ставка на рост" или "ставка на падение". Это право выбора, за которое покупатель платит `premium`.

## 2. English terms

| Term | Русское значение | Простое объяснение | Почему важно |
| --- | --- | --- | --- |
| `option` | опцион | контракт с правом, но без обязанности | вся механика курса строится вокруг этого права |
| `underlying asset` | базовый актив | BTC, ETH, SPY, AAPL | option является производным от цены этого актива |
| `call` | колл | право купить underlying | базовый bullish-инструмент |
| `put` | пут | право продать underlying | bearish-инструмент или защита |
| `strike` | страйк | цена исполнения | точка, относительно которой считается payoff |
| `premium` | премия | цена option | максимальный убыток покупателя long option |
| `expiry` | экспирация | дата истечения | время ограничено, а `theta` не спит |

## 3. Разбор понятий

### `option`

`Option` - это контракт с правом выбора. Покупатель может использовать право, если это выгодно, или не использовать, если смысла нет. Поэтому покупатель платит `premium`: бесплатного права выбора рынок обычно не выдает.

### `underlying asset`

`Underlying asset` - актив, от которого зависит option: BTC, ETH, SPY, AAPL. Option не живет сам по себе. Его цена реагирует на движение underlying, время до expiry, volatility и liquidity.

### `call`

`Call` дает право купить underlying по `strike`. Для покупателя call базовая идея bullish: актив должен вырасти достаточно сильно, чтобы покрыть premium и выйти выше breakeven.

### `put`

`Put` дает право продать underlying по `strike`. Его используют для bearish-идеи или защиты позиции. Например, long SPY put может работать как страховка от падения рынка.

### `strike`

`Strike` - цена исполнения. Это не прогноз и не цель рынка, а фиксированная точка контракта. От strike считается `intrinsic value`, breakeven и форма payoff.

### `premium`

`Premium` - цена option. Для покупателя long option это обычно максимальный убыток. Но premium также задает планку: рынок должен пройти не просто в правильную сторону, а достаточно далеко.

### `expiry`

`Expiry` - дата истечения option. Время работает против покупателя, если цена и volatility не помогают. Поэтому "направление угадал" и "сделка заработала" - не одно и то же.

### `breakeven`

`Breakeven` - цена, где итоговый P/L становится нулевым на expiry. Для long call это `strike + premium`, для long put - `strike - premium`.

### `intrinsic value`

`Intrinsic value` - внутренняя стоимость option, если исполнить его сейчас или на expiry. У call это `max(underlying - strike, 0)`, у put - `max(strike - underlying, 0)`.

### `IV crush`

`IV crush` - падение implied volatility после события. Option может подешеветь даже при правильном движении underlying, потому что рынок уже снял неопределенность с цены.

## 3. Простое объяснение

Представь, что BTC стоит $100,000. Ты хочешь получить право купить BTC через месяц по $110,000. За это право ты платишь $3,000.

Если BTC улетит к $130,000, право купить по $110,000 выглядит очень полезным.

Если BTC останется ниже $110,000, право купить по $110,000 никому особо не нужно. Option может expire worthless, то есть сгореть.

Ключевой момент: покупатель option платит за возможность, а не за гарантию прибыли. Рынок такие подарки не раздает. Он вообще больше похож на строгого преподавателя, который улыбается только после экзамена.

## 4. Два базовых типа

| Тип | Что дает | Простая логика |
| --- | --- | --- |
| `Call` | право купить underlying по strike | полезен, если актив достаточно вырос |
| `Put` | право продать underlying по strike | полезен, если актив достаточно упал |

Важно: `call` не равен "прибыль при любом росте", а `put` не равен "прибыль при любом падении". Нужно учитывать `premium`, `expiry`, `implied volatility` и liquidity.

## 5. Пример crypto: BTC call

Условие:

| Параметр | Значение |
| --- | ---: |
| Underlying | BTC |
| BTC price now | $100,000 |
| Option type | Long Call |
| Strike | $110,000 |
| Premium | $3,000 |
| Expiry | 30 дней |

Покупатель call платит $3,000 и получает право купить BTC по $110,000.

На expiry:

| BTC price на expiry | Intrinsic value | P/L покупателя |
| --- | ---: | ---: |
| $105,000 | $0 | -$3,000 |
| $110,000 | $0 | -$3,000 |
| $113,000 | $3,000 | $0 |
| $120,000 | $10,000 | +$7,000 |
| $130,000 | $20,000 | +$17,000 |

`Breakeven = strike + premium = $110,000 + $3,000 = $113,000`.

## 6. Пример traditional: AAPL call

Условие:

| Параметр | Значение |
| --- | ---: |
| Underlying | AAPL |
| AAPL price now | $200 |
| Option type | Long Call |
| Strike | $210 |
| Premium | $5 |
| Expiry | 45 дней |

Покупатель call платит $5 за право купить AAPL по $210.

На expiry:

| AAPL price на expiry | Intrinsic value | P/L покупателя |
| --- | ---: | ---: |
| $205 | $0 | -$5 |
| $210 | $0 | -$5 |
| $215 | $5 | $0 |
| $225 | $15 | +$10 |

`Breakeven = $210 + $5 = $215`.

## 7. Что может пойти не так

### Ошибка 1. "Актив вырос, значит option должен дать прибыль"

Нет. Если BTC вырос с $100,000 до $105,000, call strike $110,000 все еще out of the money. На expiry он может стоить $0.

### Ошибка 2. "Дешевый option значит хороший option"

Дешевый `premium` часто означает, что рынок считает сценарий маловероятным или что option далеко OTM. Дешевый билет на поезд не помогает, если поезд идет не туда.

### Ошибка 3. "Expiry далеко, можно не думать о времени"

Время всегда часть цены. Позже мы разберем `theta`, но уже сейчас важно знать: option имеет срок жизни.

## 8. Исторический пример

Перед важными событиями options часто дорожают: earnings у акций, решения ФРС, крупные crypto events, ETF-related news. Рынок заранее закладывает ожидание движения через `implied volatility`.

После события может случиться `IV crush`: актив даже идет в правильную сторону, но option дешевеет, потому что uncertainty исчезла. Это одна из причин, почему "я угадал направление" не равно "я заработал".

## 9. Практика

### Задание 1

ETH стоит $4,000. Ты покупаешь `ETH call`:

| Параметр | Значение |
| --- | ---: |
| Strike | $4,400 |
| Premium | $150 |
| Expiry | 21 день |

Ответь:

1. Где `breakeven`?
2. Какой `max loss`?
3. Что будет на expiry при ETH = $4,300?
4. Что будет на expiry при ETH = $4,700?

Решение:

- `Breakeven = $4,400 + $150 = $4,550`.
- `Max loss = $150`.
- При ETH = $4,300 option expires worthless, P/L = -$150.
- При ETH = $4,700 intrinsic value = $300, P/L = +$150.

### Задание 2

SPY стоит $500. Ты покупаешь `SPY put`:

| Параметр | Значение |
| --- | ---: |
| Strike | $480 |
| Premium | $8 |
| Expiry | 30 дней |

Ответь:

1. Где `breakeven` для put?
2. Какой `max loss`?
3. Что будет на expiry при SPY = $490?
4. Что будет на expiry при SPY = $460?

Решение:

- `Breakeven = $480 - $8 = $472`.
- `Max loss = $8`.
- При SPY = $490 put expires worthless, P/L = -$8.
- При SPY = $460 intrinsic value = $20, P/L = +$12.

## 10. Мини-тест

1. `Call` дает право:
   - A. купить underlying;
   - B. продать underlying;
   - C. получить guaranteed profit.

2. `Put` дает право:
   - A. купить underlying;
   - B. продать underlying;
   - C. отменить рынок, если он ведет себя некрасиво.

3. Покупатель option платит:
   - A. funding;
   - B. premium;
   - C. dividend.

4. Для long call breakeven считается как:
   - A. `strike - premium`;
   - B. `strike + premium`;
   - C. `premium / strike`.

5. Если option expires worthless, покупатель long option теряет:
   - A. premium;
   - B. весь underlying;
   - C. только настроение.

Ответы: 1-A, 2-B, 3-B, 4-B, 5-A.

## 11. Короткий вывод

- `Option` дает право, но не обязанность.
- `Call` - право купить.
- `Put` - право продать.
- `Premium` - цена этого права.
- Для long option `premium` обычно является `max loss`.
- Движение underlying в правильную сторону не гарантирует прибыль.
- Считать `breakeven` нужно сразу, до любой романтики про "рынок должен".
