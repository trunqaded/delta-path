# Crypto options

Урок 8 · `crypto-options`

## Цель

Понять, чем BTC/ETH options отличаются от equity/index options.

## Главное

Crypto options требуют учитывать:

- spot underlying;
- perps, funding, liquidation levels;
- option chain: bid/ask, IV, OI, expiry;
- platform risk, settlement, stablecoin risk.

## Практика

Открой BTC и ETH на CoinGecko, затем найди option chain для наблюдения. Выпиши nearest expiry, ATM strike, bid/ask spread, IV, OI.
