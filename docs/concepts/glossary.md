# Минимальный словарь

- Call: право купить актив.
- Put: право продать актив.
- Strike: цена исполнения.
- Expiry: дата истечения.
- Premium: цена опциона.
- ITM: опцион в деньгах.
- ATM: опцион около текущей цены.
- OTM: опцион вне денег.
- Intrinsic value: внутренняя стоимость.
- Extrinsic value: временная стоимость.
- Breakeven: цена безубыточности.
- Delta: чувствительность опциона к движению базового актива.
- Gamma: скорость изменения delta.
- Theta: распад временной стоимости.
- Vega: чувствительность к implied volatility.
- IV: implied volatility, ожидаемая рынком волатильность.
- HV: historical volatility, историческая волатильность.
- Realized volatility: фактическая волатильность после сделки.
- Open interest: открытый интерес.
- Volume: объем торгов.
- Spread: разница между bid и ask.
- Assignment: назначение исполнения опциона.
- Exercise: исполнение опциона.
- Settlement: расчет по контракту.
- Margin: обеспечение под позицию.
- Collateral: залог.
- Liquidation: принудительное закрытие позиции.
- Funding: регулярный платеж по perpetual futures.
- Basis: разница между спотом и фьючерсом.
- Skew: перекос implied volatility между страйками.
- Term structure: структура волатильности по срокам.
