# Delta Path: как начать

Delta Path - курс по опционам, где цель не "угадать рынок", а научиться понимать конструкцию риска: `underlying price`, `strike`, `premium`, `expiry`, `payoff`, `delta`, `theta`, `vega`, `implied volatility` и сценарии.

Курс устроен как единый корпус материалов. Есть два режима навигации, но не два разных курса:

| Режим | Для чего нужен | Как использовать |
| --- | --- | --- |
| С нуля | Последовательно собрать базу | Идти по урокам спокойно, без прыжков |
| Сразу главное | Быстро увидеть практическое ядро | Использовать как карту рисков и повторение |

Если сомневаешься, начинай не с выбора маршрута, а с первого урока: [Основа рынка](lessons/01-market-basics.md).

## Как устроен хороший урок

Каждый урок должен быть порцией на 20-30 минут. Не лекция на полдня, не телеграм-пост на три абзаца, а нормальный учебный кусок.

Внутри большинства уроков должны быть:

- одна главная идея;
- реальные English market terms;
- таблица или сравнительный блок;
- числовой пример;
- пример на `BTC` или `ETH`;
- пример на акции, ETF или индексе;
- мини-практика;
- короткий тест;
- блок "типичная ошибка новичка".

## Первое правило курса

Опцион - это не просто ставка "вверх" или "вниз".

Это сделка, где одновременно работают:

| Компонент | Что означает |
| --- | --- |
| `underlying price` | куда движется базовый актив |
| `time` | сколько осталось до `expiry` |
| `implied volatility` | какое движение рынок уже заложил в цену |
| `liquidity` | насколько дорого войти и выйти |
| `payoff` | что будет на экспирации |
| `position sizing` | сколько ты реально рискуешь |

У опциона может быть правильное направление и плохой результат. Да, рынок умеет быть педагогом с неприятным чувством юмора.

## Первая учебная задача

Условие:

| Параметр | Значение |
| --- | --- |
| Underlying | BTC |
| BTC price | $100,000 |
| Option | Long Call |
| Strike | $110,000 |
| Premium | $3,000 |
| Expiry | 30 дней |

Вопросы:

1. Где `breakeven`?
2. Какой `max loss`?
3. Что будет при BTC = $105,000 на `expiry`?
4. Что будет при BTC = $120,000 на `expiry`?
5. Почему рост BTC до $105,000 не спасает сделку?

Ответ:

| BTC на expiry | Intrinsic value | P/L |
| --- | ---: | ---: |
| $105,000 | $0 | -$3,000 |
| $113,000 | $3,000 | $0 |
| $120,000 | $10,000 | +$7,000 |

`Breakeven = strike + premium = $113,000`.

`Max loss = premium = $3,000`.

## Рабочий процесс

1. Читай урок.
2. Считай пример руками.
3. Отвечай на тест.
4. Записывай вывод в журнал.
5. Только потом переходи дальше.

Для первых недель достаточно paper trading. Реальные деньги подождут. Они вообще редко обижаются, когда их не торопят.
