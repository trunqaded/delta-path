# Delta Path

Delta Path учит опционам через два маршрута по одному набору материалов.

Первый маршрут - **С нуля**. Он идет плавно: сначала базовая механика рынка, потом сами опционы, затем греки, волатильность, стратегии, крипто-специфика и риск-менеджмент.

Второй маршрут - **Сразу главное**. Он нужен, если хочется быстро понять практическое ядро: где риск, где breakeven, почему опцион может потерять деньги при правильном направлении, что делают delta, theta и vega.

Цель курса - не угадывать рынок. Цель - понимать, что происходит с позицией при разных сценариях:

- если актив резко растет;
- если актив резко падает;
- если цена стоит на месте;
- если implied volatility растет;
- если implied volatility падает;
- если до экспирации остается мало времени.

## Как проходить

Выбери маршрут:

- [С нуля](paths/from-zero.md)
- [Сразу главное](paths/fast-track.md)

Оба пути используют одни и те же уроки и понятия, но в разном порядке.

Идем короткими уроками. На каждом шаге:

1. Разбираем одну идею.
2. Считаем простой пример.
3. Сравниваем крипто и обычный рынок.
4. Делаем мини-задачу.
5. Записываем вывод в журнал.

## Первая задача

Условие:

- BTC = $100,000
- Call strike = $110,000
- Premium = $3,000
- Expiry = 30 дней

Вопросы:

- Где breakeven?
- Какой максимальный убыток?
- При какой цене на экспирации сделка начнет приносить прибыль?
- Что будет, если BTC через месяц будет $105,000?
- Что будет, если BTC будет $120,000?

Ответ:

- Breakeven = $113,000.
- Максимальный убыток = $3,000.
- Прибыль начинается выше $113,000.
- При $105,000 опцион сгорает, убыток $3,000.
- При $120,000 внутренняя стоимость $10,000, прибыль $7,000.
