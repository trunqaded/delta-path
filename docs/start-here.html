Как начать

Delta Path учит видеть всю конструкцию риска: underlying price, strike, premium, expiry, payoff, delta, theta, vega и implied volatility.

Два режима навигации

РежимДля чего нуженКак использовать
С нуляПоследовательно собрать базуИдти по урокам спокойно, без прыжков
Сразу главноеБыстро увидеть практическое ядроИспользовать как карту рисков и повторение

Первое правило

Опцион - это не просто ставка "вверх" или "вниз". Это сделка, где одновременно работают цена, время, volatility, liquidity, payoff и position sizing.

КомпонентЧто означает
underlying priceкуда движется базовый актив
timeсколько осталось до expiry
implied volatilityкакое движение рынок уже заложил в цену
liquidityнасколько дорого войти и выйти
payoffчто будет на экспирации

Первая задача

BTC = $100,000, long call strike = $110,000, premium = $3,000, expiry = 30 дней.

Сначала попробуй сам: найди breakeven, max loss и P/L при BTC = $105,000, $113,000, $120,000.

Показать решение
BTC на expiryIntrinsic valueP/L
$105,000$0-$3,000
$113,000$3,000$0
$120,000$10,000+$7,000

Breakeven = strike + premium = $113,000. Max loss = premium = $3,000.
