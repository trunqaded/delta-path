# Delta Path

Учебный проект по опционам: от нуля до уверенного практического уровня на крипто- и традиционных рынках.

Delta Path строится вокруг одной идеи: один набор материалов, но два способа пройти его.

- **С нуля** - мягкий маршрут для спокойного обучения без перегруза.
- **Сразу главное** - быстрый маршрут к ключевым идеям: риск, breakeven, payoff, греки, волатильность и сценарии.

Цель проекта: не просто собрать словарь терминов, а построить понятный учебный маршрут, который учит думать как опционный трейдер: риск, вероятность, волатильность, асимметрия, хеджирование и сценарии.

## Рабочая среда

- Codex: основная среда для создания и правки проекта.
- Markdown: основной формат уроков и заметок.
- GitHub: хранение версий и публикация через GitHub Pages.
- VS Code и Obsidian: можно добавить позже, когда материалов станет много или понадобится ручная навигация по файлам.

## Структура

- `docs/start-here.md` - входная страница курса.
- `docs/roadmap.md` - карта обучения по уровням и месяцам.
- `docs/paths/` - два маршрута по одним материалам.
- `docs/lessons/` - последовательные уроки.
- `docs/concepts/` - справочник понятий.
- `docs/practice/` - задачи, шаблоны и журнал сделок.

## Принципы обучения

Каждая тема строится по схеме:

1. Одна простая идея.
2. Один пример на BTC или ETH.
3. Один пример на акции, ETF или индексе.
4. Мини-задача.
5. Сценарии: рост, падение, боковик, изменение волатильности.

## Ограничения на старте

- Только paper trading до понимания базовых рисков.
- Не продавать naked options.
- Не использовать большое плечо.
- Не торговать неликвидные опционы.
- Не открывать сделку без заранее известного максимального убытка.
